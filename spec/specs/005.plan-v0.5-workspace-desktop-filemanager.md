## 1. Latar Belakang, Risiko, dan Prinsip “Lebih Baik & Tidak Ngelag”

### 1.1 Kenapa Harus Sempurna

**v0.4** sudah ada Git UI (`GitView.tsx:8` hardcode `home`), Package Center, Share, Archive — tapi semua butuh `?root=&path=` dari File Explorer. Tanpa Workspace, user pilih `home` manual tiap reload. Tanpa Desktop, layout hilang. Tanpa File Manager lengkap, user tetap buka terminal untuk `cp/mv/trash/search`.

User minta: *“kayak punya windows file explorer nya”* + *“text editor kayak vscode, kayak terminal”* + *“bisa ada browser disana”* + *“lengkap dan sempurna, lebih baik dan nggak ngelag”*. Artinya:

- **Windows Explorer sempurna:** bukan list biasa `FileExplorerView.tsx:24` `fetch /api/v1/fs/roots` + `entries` saja, tapi **recreation pixel-perfect** Windows 11: Navigation Pane, Ribbon/Command Bar, Address Bar Breadcrumb, Search, View Modes, Preview/Details Pane, Status Bar, Context Menu, Properties, Quick Access, Drives, History, Selection model, Keyboard shortcuts, Drag-drop — semua.
- **VS Code sempurna:** `TextEditorView.tsx:36` sekarang sudah tree `TextEditorView.tsx:233`, tabs `367`, line numbers `282`, status `455`, tapi belum **Monaco/CodeMirror**: syntax highlight 20+ bahasa, bracket pair, minimap, outline, find/replace regex, multi-cursor, split editor, integrated terminal, command palette.
- **Browser di dalam:** `BrowserView.tsx:1` sekarang iframe tabs, perlu omnibox, back/forward, bookmarks, history, downloads, incognito — seperti Chrome, tapi sandboxed.
- **Lebih baik:** bukan clone lambat — lebih ringan (tanpa Electron), terintegrasi workspace (File Manager → Git → Terminal → Editor dalam 1 klik), lebih cepat (virtualized 10k file <16ms).
- **Tidak ngelag:** virtualization, lazy, debounce, cache, worker adalah acceptance criterion, bukan optimasi belakangan.

Kurang: virtualization, tree depth >1, column resize, grouping, quick access persist lebih dari favorites, search indexing, drag-drop visual, properties modal, trash progress.

### 1.3 Prinsip “Lebih Baik & Tidak Ngelag” — Arsitektur Performance (Wajib)

> **Sempurna tidak berarti lambat.** Setiap `FM/ED/BR` feature di bawah wajib lulus **performance budget** sebelum `Green` dianggap selesai.

| Layer | Teknik | Implementasi Mux | Budget |
|---|---|---|---|
| **List besar** | Virtualization | `FileExplorerView` grid/details pakai `@tanstack/virtual` atau `react-window` light (tanpa deps besar) — hanya render `~30` row visible, bukan 10k DOM. `TextEditorView` minimap juga virtual. | 10k file scroll <16ms/frame (60fps) |
| **Directory load** | Lazy + Pagination | `GET /api/v1/fs/entries?root=&path=&offset=&limit=200` + `intersectionObserver` untuk tree depth 1, bukan recursive. `src/files.rs` `list_directory` streaming. | TTFB <100ms untuk 200 entries |
| **Search** | Debounce + Worker + Bound | Input `300ms` debounce, `q` min 2 char, `max_results 100` `max_depth 5` `src/files.rs`, regex `PKG-005` `^[a-zA-Z0-9+._-]*$`, offload ke `Worker` untuk indexing. | Search 10k file <200ms |
| **Preview/Thumbnail** | Lazy + Cache | Preview hanya saat `selected.size===1 && !is_dir && size<200 KiB`, `fetch /api/v1/fs/file` + `LRU` `Map` 50 entries, image `loading="lazy"` | Preview <50ms dari cache |
| **Resize/Drag** | Debounce | `WindowFrame` `ResizeObserver` 75ms trailing `003.plan` `RSZ-006`, `DesktopIcons` drag `PointerEvents` + `requestAnimationFrame` | No resize flood |
| **Syntax Highlight** | Lazy Prism | `prismjs` 15 KiB lazy import `import('prismjs/components/prism-rust')` hanya saat `ED-002` aktif, fallback plain text. Bukan Monaco 1MB. | Highlight 5k line <100ms |
| **Frontend Budget** | Vite chunk | `prismjs`, `BrowserView` lazy `import()` → chunk terpisah, `PERF-002` 750 KiB gzip tetap hijau (sekarang 92 KiB, sisa ~650 KiB). | `npm run build` gzip ≤750 KiB |
| **Backend** | Streaming + Bounded | `src/files.rs` `list_directory` tanpa load ke RAM, `src/archive.rs:63` `sanitize`, `SessionRegistry` `MAX_SESSIONS 4` | Idle RSS ≤50 MiB `PERF-003` |

Semua `Red` test di `005b` wajib ada versi `perf` (mis. `test_fm_virt_10k_scroll_60fps`).

## 3. Threat Model — Diperluas untuk Explorer/Editor/Browser

| Skenario | Vektor | Pertahanan |
|---|---|---|
| **Workspace/ Icon traversal** | `PUT /workspaces {"path":"../../etc"}` / icon `../../../../.ssh/id_rsa` | `AllowedRoots::resolve_path` `src/paths.rs:63` + `NUL`/`..`/`\` + limit 20 ws / 100 icons |
| **File action injection** | `copy {src:"a; rm -rf"}` | `FsAction` enum `src/files.rs` typed, `std::process::Command` argv terpisah, `is_valid_package_name` regex `PKG-005` untuk search `q` |
| **Search/Index DoS** | `q=*` scan `home` 100k file | Bound `max_results 100` `max_depth 5` `q` min2, debounce 300ms, Worker |
| **Preview XSS** | `GET /fs/file?path=malicious.html` di preview iframe | Preview hanya `text/plain` + `nosniff` `src/http.rs:646`, HTML/SVG tidak dieksekusi, iframe `sandbox` tanpa `allow-top-navigation` |
| **Browser sandbox escape** | `iframe src="javascript:..."` | `sandbox="allow-scripts allow-same-origin allow-forms allow-popups"` tanpa `allow-top-navigation`/`allow-downloads`, CSP `default-src 'self'` `src/http.rs:361` |
| **Editor large file DoS** | Buka `10 MiB` log | Limit preview `200 KiB`, editor streaming `max 1 MiB` + virtualized minimap slice `3000` char `TextEditorView.tsx:495` |

## 4. Milestone A — Workspace System (`WS-001..008`) — Sempurna

**A.1 Konsep Final:** Single-folder workspace (1 `rootId+path`) — Multi-root tunda `v0.5.1`. Persist `localStorage["mux_workspace_current"]` utama + server `~/.mux-web/workspaces.json` fallback (`MUX_WEB_WORKSPACES_FILE`).

**A.2 API Lengkap:**
- `GET /api/v1/workspaces` → `[{id,name,root,path,created_ms}]` (max 20)
- `POST /api/v1/workspaces` `{name, root, path}` → `201` (validasi `AllowedRoots`, `name` regex `^[a-zA-Z0-9 _.-]+$`)
- `PUT /api/v1/workspaces/current` `{id}` → `200` + `Set-Cookie`? Tidak, cukup `localStorage`
- `GET /api/v1/workspaces/current` → `200` atau `204` jika belum set
- `GET /api/v1/git/repos?root=&path=&depth=5&limit=50` → `[{root,path,branch,dirty}]` (walk bounded, skip `node_modules/.git`)
- `GET /api/v1/workspaces/recent` → `localStorage` mirror (frontend saja)

**A.3 Frontend:**
- `web/src/apps/workspace/WorkspaceSelector.tsx` di top-bar FileExplorer + GitView: dropdown `Recent Workspaces` (max 10) + `[Set as Workspace]` + `Create Workspace` modal.
- `DesktopCanvas.tsx:12` baca `currentWorkspace` untuk `openGit/openTerminal` default path, `FileExplorerView` `onOpenInGit` sudah `DesktopCanvas.tsx:229` → `openGit(root,path)`.

### Acceptance (TDD):
- [ ] `WS-001` `POST` `../../etc` → 400 `PATH_TRAVERSAL`.
- [ ] `WS-002` `PUT /current` lalu `GET` + `localStorage` reload → sama.
