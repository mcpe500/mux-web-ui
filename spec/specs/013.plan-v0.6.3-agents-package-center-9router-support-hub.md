## 1. Latar Belakang & Risiko

### 1.1 Masalah

1. **Fitur invisible** — proot-distro management (DISTRO-001..004, spec 011) dan
   coding agents (AGT-001..006, spec 010/011) sudah terimplementasi, tapi UI-nya
   tersembunyi di belakang ikon kecil 🤖 di header editor saja
   (`web/src/apps/editor/TextEditorView.tsx:1338`). Tidak ada onboarding, tidak
   ada panduan, tidak ada tempat sentral. User tidak merasakan adanya fitur.
2. **Install agent masih manual** — keputusan D4 spec 011 membatasi instalasi
   agent ke hint statis (`src/agents.rs:11-13`). User harus mengetik sendiri
   `npm i -g …` di dalam distro.
3. **Tidak ada 9Router** — 9Router (https://9router.com/, MIT, open source)
   adalah gateway AI lokal OpenAI-compatible di `localhost:20128` dengan
   fallback 3-tier (subscription → murah → gratis) ke 60+ provider. Install via
   `npm i -g 9router`. Belum didukung sama sekali.
4. **Config agent tidak bisa diutak-atik dari UI** — mengarahkan Codex ke
   endpoint lain berarti edit manual `~/.codex/config.toml`; Claude Code berarti
   set `ANTHROPIC_BASE_URL` di `~/.claude/settings.json`.

### 1.2 Kondisi Saat Ini (fakta kode — titik awal)

| Fakta | Lokasi | Implikasi |
|---|---|---|
| Registry statis 4 agent (`opencode`, `claude-code`, `codex`, `antigravity`) + `install_hint` statis | `src/agents.rs:16-48` | 9Router belum ada; tambah entry = tambah blok + ubah test |
| Task runner argv-only single-slot dengan WS stream + cancel | `src/distro_mgmt.rs:150-318`, routes `src/http.rs:210-336` | Pola terbukti untuk diikuti task runner baru (install pkg) |
| Probe agent cache TTL 30s per `(env, agent)` | `src/agents.rs:58-90` | Dipakai ulang untuk status kartu agent di hub |
| App desktop terdaftar di union literal `appId` | `web/src/desktop/windowStore.ts:3`, `StartMenu.tsx`, `DesktopCanvas.tsx` | App baru `support` harus didaftarkan di 3 titik |

### 1.3 Risiko Tanpa Desain

- Menjalankan instalasi paket dari server = permukaan serangan baru (RCE jika
  tak tertata) → wajib argv-only, allowlist statis, tanpa `sh -c` string bebas.
- Menulis file config user (`~/.codex/config.toml` dll) bisa merusak setup user
  → wajib backup otomatis `.bak` sebelum overwrite + validasi ukuran.
- Proxy ke `localhost:20128` = SSRF-ish surface → port/address dikunci, tanpa
  URL bebas dari klien.

## 2. Threat Model

| Ancaman | Kontrol | Pemetaan SOC 2 TSC (lanjutan §10 spec 011) |
|---|---|---|
| Inject command via nama agent/env/paket | Semua argv dibangun dari allowlist statis (`registry()` × map paket npm); env divalidasi `list_environments()`; tanpa `sh -c` | CC6.8 |
| Arbitrary file write via config endpoint | Path config **diturunkan dari server** (map `agent_id → rel path` di bawah `$HOME`), bukan dari klien; batas ukuran 256 KiB | CC6.1/CC6.8 |
| Kehilangan config user saat overwrite | Backup `<file>.bak` otomatis sebelum tulis | A1.2 |
| SSRF via endpoint router | Host dikunci `127.0.0.1`, hanya port numerik (default 20128) | CC6.6 |
| Installer menggantung selamanya | Single-slot registry + cancel = SIGKILL + WS stream dapat ditutup kapan saja | CC7.4 |

## 4. Milestone B — Agents Package Center (`APKG-001..007`)

(keputusan D1 di §9).

- **APKG-001** Map paket npm statis: `opencode→opencode-ai`,
  `claude-code→@anthropic-ai/claude-code`, `codex→@openai/codex`,

## 6. Milestone D — Config Editor & Model Selector (`ACFG-001..006`)

- **ACFG-001** Map config statis server-side: `codex → ~/.codex/config.toml`,
  `claude-code → ~/.claude/settings.json`,
  `opencode → ~/.config/opencode/opencode.json`. Path TIDAK dari klien.
- **ACFG-002** `GET /api/v1/agents/:id/config` → `{path, exists, content}`.
- **ACFG-003** `PUT /api/v1/agents/:id/config` (body `{content}`, ≤256 KiB) →
  backup `<file>.bak` lalu tulis; response flag `backup_written`.
- **ACFG-004** One-click "Route via 9Router": `POST /api/v1/agents/:id/config/router9`
  (body `{port?}`):
  - Claude Code → `env.ANTHROPIC_BASE_URL=http://127.0.0.1:<port>` (JSON);
  - OpenCode → provider base URL pada opencode.json (JSON);
  - Codex → upsert blok bertanda `[model_providers.9router]` +
    `model_provider = "9router"` pada config.toml (idempoten).
- **ACFG-005** UI: panel Config & Model per agent di hub — textarea editor,
  dropdown Model Selector dari `/api/v1/router/models`, tombol Save / Route /
  Reload.
- **ACFG-006** Test: upsert TOML idempoten, JSON patch benar & field lain utuh,
  backup terbuat, tolak >256 KiB, agent tanpa config → 404 `CONFIG_UNSUPPORTED`.
