## 1. Latar Belakang

Permintaan user (2026-08-21):

> *"di code editor nya saya perlu ada supaya sekarang terminal di code editor nya jalan. terus juga di code editornya mestinya kayak vscode kan bisa open file, nah mestinya bisa open folder... jadi bisa file open file, open folder, sama terminal nya harus beneran lengkap dan sempurna."*

Kondisi saat ini:

1. **Terminal integrated masih placeholder** — `web/src/apps/editor/TextEditorView.tsx:502`
   menampilkan pesan *"💻 Integrated Terminal — open via Taskbar → Terminal"*. Belum ada PTY.
2. **Terminal yang sudah sempurna ada di app terpisah** — `web/src/apps/terminal/TerminalView.tsx:10`
   menerima prop `terminalId`, melakukan `POST /api/v1/terminals/{id}/attach` (`:53`), upgrade WS biner
   `/api/v1/terminals/{id}/ws?token=` (`:63`), xterm.js + FitAddon + debounce resize 75ms (`:139`,
   RSZ-006), exit overlay (`:182`). Komponen ini **reuse penuh** — tidak perlu tulis ulang.
3. **PTY spawn global, belum per-folder** — `src/http.rs:558` `create_terminal_handler` memakai
   `state.config.work_dir` global; tidak ada cara meminta terminal start pada folder yang dibuka editor.
4. **Open File sudah ada, Open Folder belum** — editor punya tree explorer + path input
   (`TextEditorView.tsx` `handleOpenCustomPath`), tapi root selector hanya dropdown statis
   `home/cwd` dari `GET /api/v1/fs/roots`. Tidak ada modal "Open Folder…" ala VS Code.

Tanpa 006, alur VS Code-like *open folder → integrated terminal → coding* terputus.

## 3. Threat Model

| Skenario | Vektor | Pertahanan Wajib |
|---|---|---|
| **cwd traversal** | `POST /terminals {"cwd_path":"../../etc"}` | Backend wajib `AllowedRoots::resolve_path(cwd_root, cwd_path)` sebelum dipakai sebagai `work_dir`; gagal → `400 PATH_TRAVERSAL` (pola `src/paths.rs:91-107`) |
| **NUL / encoding** | `"a\0b"`, overlong UTF-8 | Sudah ditolak resolver (`NulByteDetected`, `InvalidUtf8`) |
| **Session DoS** | Spam Ctrl+` membuka banyak PTY | Frontend reuse 1 session/editor; backend tetap `MAX_SESSIONS=4`; guard UI tampilkan `MAX_SESSIONS` message (`src/http.rs:384`) |
| **Zombie PTY saat toggle** | Show/hide berkali-kali | Toggle hanya CSS hide/show panel; WebSocket & session tetap hidup sampai window close/grace |
| **Path leak di UI** | Menampilkan absolute path sensitif | Tampil `rootId:relative` seperti pola lain; absolute hanya internal |
| **localStorage tampering** | `mux_editor_ws_*` diubah manual | Saat load, validasi ulang via `resolve_path`; invalid → fallback ke root default |

## 4. Milestone A — Integrated Terminal Beneran Jalan (`EDT-001..005`)

### A.1 Perilaku Target (VS Code parity)

1. **Buka:** tombol `>_ Terminal` di toolbar editor atau `Ctrl+```.
2. **Pertama kali:** spawn PTY baru via `POST /api/v1/terminals` dengan `cwd_*` = folder terbuka;
   render `<TerminalView terminalId={id}/>` pada split panel bawah (default 40% tinggi).
3. **Toggle berikutnya:** show/hide panel — **session sama**, tidak ada spawn kedua.
4. **Ganti folder:** user diminta konfirmasi → tutup sesi lama (`DELETE /api/v1/terminals/{id}`) →
   spawn baru dengan cwd baru. Atau pilih "keep" untuk tetap.
5. **Exit:** shell exit → overlay `Terminal Session Exited (code)`; tombol `↻ Restart` =
   spawn ulang dengan cwd sama.

### A.2 API Delta (satu-satunya perubahan backend)

```rust
// src/http.rs — CreateTerminalReq (BREAKING-ADDITIVE)
#[derive(Deserialize)]
pub struct CreateTerminalReq {
    pub cols: Option<u16>,
    pub rows: Option<u16>,
    #[serde(default)]
    pub cwd_root: Option<String>, // "home" | "cwd"
    #[serde(default)]
    pub cwd_path: Option<String>, // relative, "" = root
}
```

Handler:
```
let work_dir = match (req.cwd_root.as_deref(), req.cwd_path.as_deref()) {
    (Some(r), Some(p)) => Some(state.allowed_roots.resolve_path(r, p)
        .map_err(|e| (StatusCode::BAD_REQUEST, json!({"error":{"code":"PATH_TRAVERSAL","message":e.to_string()}})))?),
    _ => state.config.work_dir.clone(),
};
```

Field lama tanpa `cwd_*` tetap kompatibel (fallback perilaku lama). Test regresi existing
`tests/session_tests.rs`, `tests/resize_tests.rs` wajib tetap hijau.

### A.3 Frontend Wiring (`TextEditorView.tsx`)

State baru:
```ts
const [termId, setTermId]       = useState<string|null>(null);
const [showTerm, setShowTerm]   = useState(false);
const [splitRatio, setSplitRatio] = useState(0.6); // editor 60% / terminal 40%
const [spawnErr, setSpawnErr]   = useState<string|null>(null);
```

Alur `toggleTerminal()`:
```
if (!showTerm && !termId) spawn()      // EDT-001 pertama
else setShowTerm(!showTerm)            // toggle panel, session tetap
async function spawn(){
  const res = await fetch('/api/v1/terminals',{method:'POST',headers:{'Content-Type':'application/json'},
    body: JSON.stringify({cols:80,rows:24,cwd_root:ws.rootId,cwd_path:ws.basePath})});
  if(res.status===409){ setSpawnErr('MAX_SESSIONS — close another terminal'); return; }   // EDT-005
  if(!res.ok){ setSpawnErr('Spawn failed'); return; }
  const meta = await res.json(); setTermId(meta.id); setShowTerm(true);
}
```

Split panel: container flex-column; drag divider 6px (`PointerEvents`+`RAF`) mengubah
`splitRatio` clamp `0.25..0.75`. `TerminalView` otomatis re-fit via observer-nya (RSZ-006).

Label header terminal: `💻 bash — home:/work/app` (rootId:relative).

### A.4 Acceptance Milestone A
- [ ] `Ctrl+`` pertama → panel muncul, prompt shell **berada di folder terbuka** (verifikasi `pwd`).
- [ ] Toggle show/hide 5× → jumlah session `/api/v1/terminals` tetap 1 (tidak duplikat).
- [ ] Resize divider → output tidak rusak; `stty size` sesuai visual (fit benar).
- [ ] `exit` → overlay `Terminal Session Exited`; `Restart` → prompt baru cwd sama.
- [ ] `cwd_path:"../.."` → `400 PATH_TRAVERSAL`, tidak ada PTY dibuat.
- [ ] Saat 4 session aktif → pesan `MAX_SESSIONS` ramah, tidak crash.

## 5. Milestone B — Open File & Open Folder ala VS Code (`EDT-006..010`)

### B.1 `FolderPicker.tsx` (komponen reusable)

Props:
```ts
{ mode:'folder'|'file',
  initial?: {rootId:string, path:string},
  onSelect:(sel:{rootId:string,path:string})=>void,
  onClose:()=>void }
```

UI (Windows 11 Fluent, konsisten Toolbar/StartMenu):
- Header: title + close ✕.
- Sidebar mini: daftar roots (`GET /fs/roots`).
- Body: breadcrumb klik + listing `GET /fs/entries` **depth-1 per navigasi** (lazy, no-lag);
  double-click folder = masuk; single-click select; file hanya selectable saat `mode:'file'`.
- Footer: input path manual + tombol `Cancel` / `Select`.

Keamanan: semua navigasi tetap lewat API (backend resolve); frontend tidak pernah kirim absolute path.

### B.2 Editor Workspace State (`EDT-007`)

```ts
interface EditorWS { rootId:string; basePath:string }
const [ws,setWs] = useState<EditorWS>(loadOr(()=> ({rootId:'home', basePath:''}), winId));
useEffect(()=>{ localStorage.setItem(`mux_editor_ws_${winId}`, JSON.stringify(ws)); reloadTree(ws); },[ws]);
```
- `reloadTree` = `loadDir(ws.rootId, ws.basePath||'/')` + reset `expandedDirs`.
- Validasi saat load: fetch entries; gagal → fallback default (jangan stuck error).

### B.3 Menu & Shortcut (`EDT-008`)

Menu **File**: `New Tab Ctrl+N` • `Open File… Ctrl+O` • `Open Folder… Ctrl+K O` • separator • `Save Ctrl+S`.
Shortcut global editor:
- `Ctrl+O` → picker `mode:'file'` → hasil `openFile(rootId, path)` (existing).
- `Ctrl+K` lalu `O` (chord, ala VS Code) → picker `mode:'folder'` → `setWs(sel)`; tanya keep/replace terminal (A.1 poin 4).
- `Ctrl+`` → toggle terminal (existing binding diperluas).

### B.4 Terminal Ikut Folder (`EDT-009`)

Header terminal menampilkan `bash — ${ws.rootId}:${ws.basePath||'/'}`. Ganti folder → dialog:
`Replace terminal cwd? [Replace] [Keep]` (default Replace bila session idle, Keep bila ada proses berjalan — deteksi sederhana: selalu tanya).

### B.5 Status Bar (`EDT-010`)

Kiri: `[HOME] /work/app` (folder aktif). Tengah: `Ln, Col` (existing). Kanan: `⎇ main*` dari
`GET /api/v1/git/status?root=&path=` poll 30s debounce; gagal/404 → sembunyikan segmen branch.

### B.6 Acceptance Milestone B
- [ ] `File→Open Folder…` → pilih `home:/work/app` → tree reload, breadcrumb update, persist reload.
- [ ] `Ctrl+O` → pilih file → tab terbuka (reuse `openFile`), dirty tracking benar.
- [ ] Setelah ganti folder, `pwd` di terminal (Replace) = folder baru.
- [ ] Status bar menampilkan branch repo yang dibuka; non-repo → segmen hilang.
- [ ] localStorage korup → fallback default tanpa crash.

## 7. Performance Budget — Tidak Ngelag

| Aspek | Teknik | Batas |
|---|---|---|
| Spawn PTY | On-demand sekali per editor; reuse saat toggle | ≤1 PTY/window; total ≤ MAX_SESSIONS |
| Panel resize | `PointerEvents`+`RAF` ubah `splitRatio`; fit debounce 75ms milik TerminalView | Tidak ada frame >16ms saat drag |
| FolderPicker | Fetch depth-1 per navigasi; tidak recursive scan | Navigasi <100ms TTFB lokal |
| Tree reload | Hanya root berubah; anak tetap lazy expand | Reload <50ms |
| Git badge | Poll 30s debounce, abort saat window minimize | CPU idle ~0 |
| Bundle | Tidak ada dep baru (semua reuse); `FolderPicker.tsx` ~3 KiB | gzip tetap ≤750 KiB (kini 95.39) |
