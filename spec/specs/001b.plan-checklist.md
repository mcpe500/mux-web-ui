# Mux Web UI — v0.2 Implementation Checklist & Verification Matrix

Status: completed (v0.2 ready & released)  
Companion to: [`001.plan-v0.2.md`](./001.plan-v0.2.md)  
Rule: Every task requires TDD Red -> Green -> Refactor execution. A milestone is
not done because the UI looks like it works; the acceptance tests must pass.

---

## TDD Execution Loop Standard

For every item:
1. **Red**: Write a failing test for the item before production code.
2. **Green**: Write minimal code to pass the test.
3. **Refactor**: Clean up while keeping tests green.
4. **Verify**: Run full test suite (unit + integration) & budget checks.
