## 2. Threat Model (lanjutan §10 spec 011 + §2 spec 014)

| Ancaman | Kontrol |
|---|---|
| URL injection via `--url` / env | Allowlist ketat: hanya `https://raw.githubusercontent.com/mcpe500/mux-web-ui/...` dan `https://github.com/mcpe500/mux-web-ui/releases/...` dan `https://raw.githubusercontent.com/mcpe500/...` prefix; else `INVALID_URL` |
| `sh -c` arbitrary — pengecualian terdokumentasi | Hanya path update yang boleh `bash -c 'curl ... | bash'`; argv lain tetap tanpa `sh -c`; curl harus ada else `CURL_MISSING` |
| Downgrade paksa | Tidak dicegah di v1 (install.sh ver_cmp Latest vs Current `update.sh:172` sudah early-exit jika not lt); subcommand tidak downgrade manual — sama |
| Self-overwrite while running | `install.sh:202-206` atomic `mv -f` + `install -m 0755` + backup; proses lama tetap jalan sampai restart — doc “restart required” |

## 3. Milestone UPD (`UPD-001..004`)

- **UPD-001** Help: `mux-web --help` menampilkan `Commands: update`; `mux-web update --help` menampilkan `--check` dan `--url`.
- **UPD-002** Streaming update: `mux-web update` → validasi allowlist URL default `https://raw.githubusercontent.com/mcpe500/mux-web-ui/main/install.sh` → spawn `bash -lc 'curl -fsSL "<url>" | bash'` inherit stdout/stderr; exit code diteruskan; respect `MUX_WEB_UPDATE_URL` env override dan `MUX_WEB_STRICT_VERIFY`.
- **UPD-003** Dry-run: `mux-web update --check` → fetch `GET https://api.github.com/repos/mcpe500/mux-web-ui/releases/latest` (via `curl -fsSL` juga, fallback `Cargo.toml` raw) parsing `tag_name vX.Y.Z`, banding `CURRENT` (`env!("CARGO_PKG_VERSION")`), print Indonesian pesan `Sudah versi terbaru vX` atau `Update tersedia vY (saat ini vX) — jalankan \`mux-web update\``.
- **UPD-004** Guard: URL non-allowlist → `INVALID_URL` stderr + exit 1 tanpa spawn curl; `--url` dengan spasi/`;`/`&&` tetap satu arg validasi prefix saja (allowlist sudah blok).
