# Mux Web UI — Implementation Checklist & Verification Matrix

Status: Completed  
Companion to: [`000.plan.md`](./000.plan.md) and [`000a.plan-test.md`](./000a.plan-test.md)  
Rule: Every task requires TDD Red -> Green -> Refactor execution. Verified by automated unit/integration tests and binary budget script.

---

## TDD Execution Loop Standard

For every item:
1. **Red**: Write a failing test for the item before production code.
2. **Green**: Write minimal code to pass the test.
3. **Refactor**: Clean up and optimize code while keeping tests green.
4. **Verify**: Run full test suite & budget checks.
