## 1. Latar Belakang & Risiko

### 1.1 Skenario User

1. **Data scientist di HP**: membuka `analysis.ipynb` hasil kerja laptop — ingin
   membaca narasi markdown, melihat grafik output, mengedit satu cell lalu
   mengeksekusinya ulang tanpa buka laptop.
2. **Developer Python**: edit `main.py` lalu tekan ▶ untuk menjalankan langsung —
   output muncul di panel bawah, pilih env Termux atau distro.
3. **Membaca dokumen**: double-tap `paper.pdf` di workspace → terbuka reader
   proper (outline, zoom, search), bukan unduhan mentah / layar putih WebView.
4. **Coding agent-first**: menjalankan Codex pada proyek sambil melihat chat yang
   rapi (apa yang dikerjakan agent, approval saat butuh izin), bukan raw scroll terminal.

### 1.3 Risiko Tanpa Desain

- **Eksekusi sembarangan** = RCE-by-UI. Tanpa allowlist interpreter + validasi
  path ketat, tombol Run menjadi pintu masuk eksekusi bebas (CC6.8).
- **Output flood**: `print('A'*10**9)` atau traceback raksasa harus dibatasi ring
  agar tab tidak OOM.
- **nbformat berbahaya**: cell output base64 puluhan MB / struktur aneh → parser
  wajib cap ukuran + render lazily (collapse) agar webview mobile tidak mati.
- **Format drift CLI Codex**: pemetaan event rapuh antar versi CLI; tanpa
  fallback otomatis, fitur "chat" menjadi layar kosong.
- **Regresi janitor/reconnect**: session Run menyertai prinsip AFK spec 012 —
  job run jangan ikut tereap selama streaming (busy-grace existing mencakup).

## 2. Threat Model (lanjutan SOC 2 TSC §10 spec 011)

| Ancaman | Kontrol | Pemetaan TSC |
|---|---|---|
| Inject command via nama file/env/cell | Interpreter dari map statis (`python3`/`ipython`/`jupyter`); argv `Vec<String>` pre-fork; path via `AllowedRoots::resolve_path`; TANPA `sh -c` string bebas | CC6.8 |
| Run dipakai sebagai konsol arbitrer (mengangkut `-c '...'`) | Argv hanya `[INTERP, <abs-path>]` — kode user TIDAK pernah lewat argv; temp script ditulis via fs API tervalidasi + prefix `.mux-run-*` di workspace, dihapus after-run | CC6.1/CC6.8 |
| Output flood → OOM webview/server | Ring buffer terbatas per task (pola PTY ring); truncate marker `[output truncated]` | A1.1 |
| nbformat malicious (zip-bomb-like base64, depth) | Cap fetch ≤`MUX_WEB_DOC_MAX_BYTES`; parser depth/count guard; outputs >256 KiB collapsed (lazy render on tap) | CC7.4 |
| PDF mengeksploit parser js | pdf.js sandboxed worker origin-same; js/embed actions dinonaktifkan; versi dipin + audit CI (SEC-007 menjangkau npm via cargo? npm audit job frontend) | CC6.6 |
| Codex approval auto-eksekusi | Approval card HANYA meneruskan konfirmasi keystroke ke PTY yang sama; tidak ada kanal eksekusi kedua; default-deny untuk pattern `--dangerously` di prompt library | CC6.8 |
| Timeout tak berujung | `MUX_WEB_RUN_TIMEOUT_SECS` default 300; cancel = SIGKILL (pola registry) | CC7.4 |

## 3. Milestone A — Notebooks 📓 (`NB-001..012`)

App window **📓 Notebooks** terdaftar di desktop; membuka satu/multi dokumen
(model tabs internal window, state persist per winId).

### Struktur data & renderer (client-side)
- **NB-001** Parser `nbformat` minimal (v4, fallback v3→v4 migrate ringan):
  `{cells:[{cell_type,source,outputs[],metadata}],metadata}` → model immutable
  in-house. Vitest fixture: notebook standar, outputs stream/error/image,
  notebook >256 KiB output, JSON korup → error UI rapi bukan crash.
- **NB-002** Renderer cells: markdown (subset renderer in-house D7: heading,
  bold/italic/code, list, link, blockquote, fenced code w/ highlight mux-code),
  code source editable (textarea overlay transparan + layer highlight, pola
  EDIT EDITOR LAMA), raw. Output types: stream/stderr, error (traceback styled),
  execute_result/display_data (text/plain & image/png-jpeg-gif via data-URL),
  vega/app-state → placeholder badge "unsupported output".
- **NB-003** Guard kapasitas: outputs >256 KiB collapse "show more"; gambar decode
  lazy saat cell masuk viewport (IntersectionObserver).

### Edit & save
- **NB-004** Edit cell source (markdown/code) → dirty tracking per dokumen → save
  `PUT /api/v1/fs/file` (existing) dengan serialisasi kembali ke nbformat asli;
  conflict path = reuse flow save-conflict editor (EDIT-006).
- **NB-005** Operasi cell: add/delete/move up-down/change-type/code↔markdown —
  semua pure functions di `notebookModel.ts` + vitest tabel kasus.

### Eksekusi ladder
- **NB-006** Backend `GET /api/v1/tools/envcheck/:env_id?bin=jupyter,ipython`
  → probe gabungan memakai `probe_agent` mekanisme (cache TTL 30s) mengembalikan
  `{python, ipython, jupyter}` boolean.
- **NB-007 L1 Execute All**: `POST /api/v1/notebooks/execute-all` body `{root,path,env_id}`
  → builder `nb_execute_argv(env_id,path)` = `[proot?] jupyter nbconvert --to
  notebook --execute --stdinout`? — TIDAK: file di-place di workspace nyata →
  `... --output <tmp>.ipynb <path>` argv-only; hasil dibaca ulang + diff output ke
  UI (hanya cells yg berubah re-render). Status stream memakai WS task pattern.
  JUPYTER_MISSING → hint statis cara install (per distro pm map).
- **NB-008 L2 Run Cell-to-cursor**: `POST /api/v1/notebooks/run-prefix` body
  `{..., upto_index}` → serializer `cellsToScript(0..N)` dengan marker
  `# %% MUXCELL N` (pure fn + vitest) → tulis temp `.py` via PUT fs guard → jalankan
  runner → parser stdout segmen per-marker → merge ke outputs cell tsb
  (text/plain & error saja; rich media ditandai badge "run via L1/kernel").
- **NB-009 L3 Kernel Bridge (experimental, default OFF)**: settings toggle per
  install; hidden PTY `jupyter console --simple-prompt` mengikuti pola attach
  TerminalView (backoff spec 012); inject cell delimiters + scrape matplotlib
  inline PNG (`%config InlineBackend`). Markerexperimental jelas di UI; disable
  otomatis bila probe gagal. **Bukan tujuan v0.6.4 zero-ZMQ kernel production** —
  bridge ini jembatan pragmatis; doc limitations di handoff.
- **NB-010** Session live status bar notebook: kernel/L-level aktif, last run dur,
  busy spinner cancel-safe.

### Acceptance criteria
- [ ] Buka `analysis.ipynb` 1–5 MB → render <1.5 s di device mid-range; scroll mulus.
- [ ] Edit markdown + source → save → reload persist benar; file IPYNB valid kembali.
- [ ] Execute All di env berjupyter mengganti outputs sesuai; env tanpa jupyter →
      pesan + hint, tanpa spawn sia-sia.
- [ ] Run Cell ▶ (L2) menampilkan stdout segmen tepat ke cell terkait.
- [ ] Semua Red vitest/cargo di atas hijau; regresi nol.

- **AGX-006** Drift handling: unparsable-ratio > threshold dalam window event →

- **AGX-007** Prompt library: penyimpanan localStorage per-workspace (CRUD +

- **AGX-008** History drawer: daftar task run lampau pada project (dari log lokal

- **AGX-009** Multi-agent generalisasi dimuka: adapter interface `AgentSurfaceAdapter`

- **AGX-010** Security wiring: semua eksekusi tetap argv-only via existing
  quick-launch; tidak ada endpoint backend BARU di milestone ini (0 backend changes)
  kecuali apabila probe model-info diperlukan (reuse).
