## 1. Latar Belakang & Risiko

### 1.1 Skenario User

1. **Editor nyaman dipakai**: buka file Rust/TS berisi komentar blok multi-line
   → highlight salah (baris kedua `/* … */` tidak terwarnai); kurung tidak
   otomatis tertutup; wrap tidak bisa di-on/off.
2. **File besar**: file ≥200 KB langsung kehilangan highlight (cap saat ini),
   gutter nomor baris merender ribuan node DOM → lag di webview mobile.
3. **Quick-launch agent ke folder lain**: Agents menu terkunci ke workspace
   aktif — user ingin menjalankan `opencode` di proyek lain tanpa pindah folder.
4. **Reload halaman**: layout grup/tab terminal lenyap (sesi PTY hidup di
   server tapi tabnya hilang).
5. **Akses via reverse-proxy**: rate-limit pairing menghitung IP proxy, bukan
   klien asli; hostname wildcard (`*.ts.net`) harus didaftarkan satu per satu.
6. **Update aman**: installer hanya cek SHA-256 yang ikut ter-download dari
   lokasi sama — kompromi upstream = kompromi checksum. Butuh signature.
7. **Kelola distro**: pasang/hapus distro proot-distro harus lewat terminal
   manual; ingin UI dengan progress dan guardrail.

### 1.3 Risiko Tanpa Desain

- **Virtualisasi merusak caret/IME** bila textarea disentuh — desain wajib
  mempertahankan textarea native utuh, hanya overlay digeser.
- **Wildcard allowlist melebarkan trust** ke pemilik suffix (DNS rebinding) —
  wajib opt-in eksplisit + warning startup.
- **Spoof `X-Forwarded-For`** dari peer tak-tepercaya dapat memutar rate-limit —
  resolusi IP harus walk chain dari kanan melewati trusted saja.
- **`proot-distro remove` destruktif** — wajib konfirmasi ketik-id + log stream.
- **Kompromi kunci signing** — key hanya di GitHub secret; pubkey publik di-repo;
  rotasi didokumentasikan.

## 3. Threat Model

### Yang dilindungi

- **Auth gerbang segala endpoint baru** (`install/remove/tasks/hints`) — tidak
  ada jalur unauthenticated baru; POST state-changing tetap lewat CSRF (SEC-005).
- **Eksekusi command hanya dua bentuk**: (a) `proot-distro install|remove <id>`
  dengan id lolos regex `^[a-z][a-z0-9-]*$` **dan** membership daftar resmi
  hasil `proot-distro list`; (b) binary agent dari registry statis (D5 v0.6.1
  diperluas: instalasi agent via server **ditolak by design** — hanya hint
  teks statis). Tanpa `sh -c` di jalur baru mana pun.
- **Proxy spoofing** (NET-007): header forwarded dari peer yang bukan trusted
  proxy diabaikan total (perilaku default); chain ditelusuri kanan→kiri dan
  berhenti pada hop tak-tepercaya pertama; Host gate tidak membaca forwarded.
- **Wildcard rebinding** (NET-008): risiko residu terdokumentasi — wildcard
  mendelegasikan trust kepada pemegang suffix; mitigasi = opt-in sintaks
  eksplisit + warning startup mencantumkan tiap entri wildcard; default config
  tidak berubah.
- **Supply chain** (SIGN): artifact diverifikasi minisign (pubkey di-repo,
  key offline/secret); tampered checksums + stale sig gagal-closed; mode strict
  tersedia untuk host yang menuntut verifikasi penuh.
- **XSS surface tidak bertambah**: layer highlight tetap lewat escape HTML
  jalur existing (`esc` di TextEditorView); bracket/wrap/virtualisasi tidak
  membangun HTML dari input baru.
- **Task destruktif** (DISTRO remove): konfirmasi ketik-id di UI + stream log +
  satu-task guard + cancel; operasi berjalan sebagai user yang sama (tanpa
  privilege baru — terminal existing sudah sanggup hal yang sama).

### Yang tidak dilindungi (di luar scope threat model)

- Sertifikasi formal SOC 1/2/3 = proses audit organisasi (AICPA) — bukan hasil
  rilis kode; yang diberikan adalah kontrol engineering + jejak bukti (§10).
- Proses dalam distro tetap shell penuh milik user (sandboxing bukan tujuan).
- Jaringan browser↔server mengikuti AUTH/LAN/NET existing; ACME/TLS otomatis
  tetap out-of-scope.

## 4. Milestone A — mux-code Polish: Komentar Blok Multi-line, Bracket Auto-close, Wrap Toggle (`EDIT-017`, `EDIT-013`, `EDIT-014`)

### Perilaku

1. **Tokenizer stateful (EDIT-017)**: `tokenizeLineStateful(line, lang,
   inBlock=false)` → `{tokens, inBlock}`; pass highlight mem-folding state
   antar baris. Wrapper signature lama `tokenizeLine(line, lang): Token[]`
   dipertahankan (delegasi state awal `false`) sehingga 70 vitest existing
   hijau tanpa edit.
2. **Bracket auto-close (EDIT-013)**: modul murni `mux-code/brackets.ts` —
   `onSelfInsert(before, after, ch)` → mutasi teks + posisi seleksi atau null;
   wire di `handleKeyDown` sebelum cabang Tab (pola restore-caret existing).
3. **Wrap toggle (EDIT-014)**: state `wrapOn` persist `mux_editor_wrap_<winId>`;
   tombol toolbar + item View; textarea & `<pre>` highlight memakai
   `whiteSpace` sama; gutter nomor baris disembunyikan saat ON (alignment
   logis rusak oleh wrap); chip statusbar `Wrap: ON/OFF`.

### Keputusan desain

- State tokenizer = boolean `inBlock` tunggal (bahasa tabel existing tak punya
  blok bersarang); string `/*` di dalam literal tidak membuka blok (urutan
  cek: comment → string seperti sekarang).
- Bracket logic murni tanpa DOM agar table-driven vitest; undo tetap native
  (satu mutasi per keystroke). Backspace hapus-pasangan = stretch opsional.
- Wrap OFF adalah perilaku lama persis (default).

### Acceptance criteria

- Vitest Red: js/rust blok ≥3 baris; blok tak tertutup; `//` di dalam blok;
  `/*` dalam string; py/sh/json/md tidak berubah.
- Vitest Red brackets: tabel kasus (open/close/skip-over/wrap-seleksi/kutip-
  antar-word); wiring: caret benar setelah insert.
- Regresi: 70 vitest lama hijau tanpa edit; budget PASS.

## 5. Milestone B — Virtualisasi Penuh (`EDIT-018`)

### Perilaku

1. Cache state per-baris inkremental (`mux-code/lineStates.ts`, murni):
   `syncLines(cache, newText)` diff prefix/suffix → `update(start, removed,
   inserted)` invalidasi ekor; `tokensFor(lines/lang, from, to)` token window
   dari state awal `from`.
2. Render: gutter dan layer `<pre>` hanya baris `[start..end]` dari
   `visibleRange(scrollTop, viewportH, lineH=21)` (`engine.ts:119`); offset
   `translateY(16 + start*lineH − scrollTop)` (+ translateX sinkron scrollLeft
   untuk layer highlight); scroll handler rAF-throttled (pola PERF-006).
3. **Textarea tetap utuh** (caret/selection/IME native) — hanya overlay
   digeser; escape HTML jalur existing.
4. Cap highlight 200 KB → **2 MB** hard-guard (di atasnya plain tanpa crash).

### Keputusan desain

- Invalidasi diff-aware dari perubahan konten (common-prefix/suffix line diff);
  fallback recompute ekor penuh — kebenaran > kecerdasan.
- `LINE_H = 21` diekspor konstanta (14px × 1.5 lineHeight existing).

### Acceptance criteria

- Vitest: konsistensi `tokensFor(window)` == tokenisasi ulang penuh; edit satu
  baris tengah dokumen hanya merekomputasi ekor; gutter/highlight window ≤
  viewport + overscan baris.
- Manual smoke: file 10 ribu baris scroll mulus; budget gzip delta <5 KiB.

## 8. Milestone E — Network Hardening: Trusted Proxy + Wildcard Allowlist (`NET-007/008`)

### Perilaku

1. **NET-007**: flag `--trusted-proxies` CSV ip/cidr, divalidasi fail-fast
   entry bernomor; helper `effective_client_ip(peer, headers, cfg)`: telusuri
   `X-Forwarded-For` kanan→kiri melewati peer trusted, berhenti di hop
   tak-tepercaya pertama; dipakai rate-limit pairing + log tracing; Host gate
   tidak berubah. Tanpa flag → perilaku lama byte-for-byte (terkunci test).
2. **NET-008**: parser allowlist menerima `*.suffix` (dot-boundary: cocokkan
   suffix sendiri ATAU subdomain apa pun); tolak `*` telanjang dan `*.`;
   startup mencetak warning per entri wildcard; interaksi advertise implisit
   (D3 spec 009) tidak berubah.

### Keputusan desain

- Parser CIDR tanpa dependensi baru (match oktet manual); wildcard hanya di
  `--allowed-hosts`, bukan di advertise.
- README bagian network diperbarui (contoh kombinasi `--allowed-hosts '*.ts.net'
  --trusted-proxies 100.64.0.0/10`).

### Acceptance criteria

- Red security tests: matrix spoof (peer untrusted + XFF → diabaikan; chain
  trusted penuh → klien asli; cidr match/partial tidak match); wildcard
  valid/invalid tabel kasus; rate-limit per-IP (H2) tetap hijau.
- Regresi: seluruh suite AUTH/SESS/LIFE/NET hijau tanpa edit.

## 9. Milestone F/G — Release Signing (`SIGN-001..003`) & Manajemen Distro (`DISTRO-001..004`)

### Milestone F — Signing

1. Alat: **minisign** (tersedia di Termux `pkg install minisign`; statis;
   model key sederhana). Pubkey di-commit `share/minisign.pub`; private key
   hanya GitHub secret `MINISIGN_SIGNING_KEY`; prosedur generate offline:
   `minisign -G -p share/minisign.pub -s minisign.key` (key TIDAK pernah di-repo).
2. CI `release-summary`: sign `checksums.txt` → upload `checksums.txt.minisig`;
   langkah signing bersifat kondisional (`[ -n "$MINISIGN_SIGNING_KEY" ]`)
   agar rilis pra-konfigurasi-secret tetap jalan dengan warning.
3. `install.sh`/`update.sh`: unduh `checksums.txt` + `.minisig`; bila
   `minisign` terpasang → verifikasi SEBELUM sha256 per-binari (tampered →
   abort, binari lama utuh); bila tidak ada → SHA-256-only + warning kuning
   mencolok; `MUX_WEB_STRICT_VERIFY=1` → tanpa minisign fatal. Pubkey dibaca
   dari `MUX_WEB_MINISIGN_PUB` (override hermetic test) atau embedded di script.
4. Scenario installer-test 5a/5b/5c (valid / tampered / strict-tanpa-minisign)
   dengan fixture staging pola scenario 3 existing; CI scenario generate
   keypair sementara sendiri.

### Milestone G — Manajemen distro + hint agent

1. `src/distro_mgmt.rs`: `available_vs_installed()` (base dir injectable;
   available dari `proot-distro list --terse` full, installed dari fs);
   `install_argv(id)` → `["proot-distro","install",id]`; `remove_argv(id)` →
   `["proot-distro","remove","-y",id]` (flag diverifikasi saat impl — Q2);
   id lolos regex `^[a-z][a-z0-9-]*$` + membership daftar resmi.
2. Endpoint + task stream: `POST /api/v1/environments/:id/install|remove` →
   `{task_id}`; `GET /api/v1/environments/tasks/:id/stream` WS relay
   stdout/stderr + exit code; global satu-task guard → 409 `TASK_BUSY`;
   `DELETE /api/v1/environments/tasks/:id` cancel SIGTERM→SIGKILL 5s;
   unknown id → 400. Tokio proses langsung (tanpa shell).
3. Registry `src/agents.rs` tambah field statis `install_hint` (teks, mis.
   `npm i -g opencode-ai`); field ikut ter-serialize di response agents
   (additive). **Server tidak pernah mengunduh/mengeksekusi installer agent.**
4. UI modal ⚙️ di chips environment: installed [Terminal] / available [Install]
   (konfirmasi ketik-id untuk remove); progress bar dari stream; disable saat
   task aktif.

### Acceptance criteria

- Red unit: argv builder persis; id liar (`../../etc`, uppercase, spasi) → Err.
- Red integration (fake `proot-distro` di PATH milik test): guard 409; stream
  mengirim baris + exit code; cancel menghentikan child (LIFE-002 no-orphan
  tetap hijau).
- Vitest: modal render, disable saat busy, konfirmasi remove.
