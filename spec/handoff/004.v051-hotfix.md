## 3. Fakta Kode Penting (untuk session berikutnya)

- Respons create kini: `{id, token, cols, rows, state, pid, work_dir?}` — `work_dir` hanya
  muncul saat cwd eksplisit di-resolve (payload legacy tanpa `cwd_*` dan config tanpa
  `--work-dir` → field ABSEN; test mengunci ini agar wire lama stabil).
- Label header editor sengaja menampilkan **basename** + absolute di `title`; reverse-map
  penuh absolute→relative ditunda (Q1 MVP decision, lihat checklist §6).
- `gateState(undefined)` = pending (fetch belum selesai) → warn chip tanpa banner;
  jangan ubah jadi red sebelum health sempat jawab.
- Font `unicode-range` harus persis sama dengan range pyftsubset; menambah glyph =
  subset ulang + update komentar checksum di `main.css`.
- `terminalConfig.test.ts` memakai stub semantik xterm (`loadAddon→activate`);
  JANGAN assert `constructor.name` (dimangle transform vitest → string kosong).
- **GOTCHA runtime**: `Terminal` wajib dibuat dengan `allowProposedApi: true` —
  `term.unicode.*` adalah proposed API @xterm/xterm 5.x; tanpa itu loadAddon
  melempar Error saat activate() dan terminal blank (sudah difix di
  `TerminalView.tsx`, commit 42d7bb4). Stub test tidak menangkap ini karena
  bypass opsi konstruktor asli.

## 5. Konteks untuk Session Berikutnya

- Root cause bug lapangan = version skew (RC-01): frontend v0.6 + backend tua diam-diam
  mengabaikan `cwd_*`. Kini terdeteksi: chip versi + banner merah. Kalau user masih
  melaporkan `pwd` salah SETELAH install 0.5.1, cek dulu apakah banner merah tampil
  (berarti binary belum ter-update, bukan regression).
- Multi-root workspace (tunda sejak 005 §8) tetap out-of-scope; Q1 reverse-map bisa
  naik prioritas kalau user minta label relative presisi.

**Gotcha CI yang diperbaiki (`.github/workflows/ci.yml`, commit beruntun di atas 180a150):**
1. `cross-check`: zstd-sys butuh clang NDK — pakai NDK preinstalled runner
   (`ANDROID_NDK_ROOT`) + wrapper `aarch64-linux-android24-clang` langsung; **cargo-ndk
   dibuang** karena panic saat startup dengan cargo stable baru (juga di job release android).
2. `installer-test`: staging hardcoded `0.3.0` vs app `0.5.1` → versi dinamis dari Cargo.toml
   (`STAGED_VERSION`); Scen.3 mengembalikan sha256 setelah uji korupsi; Scen.4b pin
   `MUX_WEB_NO_FALLBACK=1` agar hermetic.
3. Release `aarch64-unknown-linux-gnu`: rustc stable default ke bundled rust-lld via shim
   host → emulasi x86_64 menolak `--fix-cortex-a53-843419`; fix = linker silang asli +
   `-Clink-self-contained=no` (komponen `-linker` ternyata nightly-only di target ini).
4. `release-summary`: tambah `permissions: contents: write` (403 sebelumnya).

Rilis v0.5.1 ini dipublikasikan manual via `gh release create` dari artifact CI run
32580493530 (semua target hijau) karena izin token belum ada saat itu; tag berikutnya
sudah otomatis.
