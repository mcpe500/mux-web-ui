- `effective_allowed_hosts()` adalah sumber kebenaran tunggal; `advertise-addr` host-part di-merge di sana (implisit). Jangan duplikasi allowlist di `AppState`.
- `is_gate_ok_ip` dipakai di dua tempat (gate + banner) — ubah di `config.rs` saja.
- `effective_advertise_addrs()` skip entri CSV kosong (noisy `Some("")` dari helper test) — jangan ubah jadi error keras untuk kosong.
- `host_origin_middleware` masih `is_private` dihapus; gate kini `is_gate_ok_ip`; `unwrap_or_default` aman karena startup fail-fast; tapi `Some("")` helper test harus dihindari (sudah fix: `if !allowed.is_empty()`).
- `clap` long name singular dipaksa untuk advertise; penambahan flag baru perhatikan pluralisasi derive.
- `collect_access_urls` pure — تستable; urutan port di host: `format!("{scheme}://{a}")` advertise sudah termasuk port bila ada.
