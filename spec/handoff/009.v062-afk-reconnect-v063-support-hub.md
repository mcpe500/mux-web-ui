## 1. Yang Dikerjakan

### Spec 012 — Terminal Resiliensi saat AFK (`AFK-001..011`)
- `web/src/apps/terminal/TerminalView.tsx`: ekstrak **`attach()` reusable**; `ws.onclose` → backoff eksponensial **500ms→1s→2s→4s→cap 10s** (`setTimeout`, cleanup di effect-return); **guard satu socket** (`socketRef`+`timerRef`) — socket lama dipaksa close sebelum open baru; loop berhenti permanen pada `/attach` **404 SESSION_NOT_FOUND** dan frame **EXIT (0x03)** (overlay penuh hanya untuk itu).
- Kehadiran tab: `visibilitychange→visible` saat putus ⇒ reconnect **immediat** (tanpa menunggu backoff); tab `hidden` ⇒ pause timer; `pagehide`/`beforeunload` ⇒ close rapi + batalkan retry. Indicator ringan `<span class="term-reconnect">• Menghubungkan ulang…</span>` (bukan overlay).
- Server retention: `src/config.rs:63-64` default `session_idle_timeout` **60→120 s** + env `MUX_WEB_SESSION_IDLE_TIMEOUT`; `src/session.rs:55` `grace_period` default 120 s. `=0` tetap berarti reap OFF (SESS-010 utuh). Reattach tetap clear `idle_deadline` (AFK-010).
- Tests: vitest mock WebSocket (backoff sequence, single-socket, 404-stop, EXIT-stop, visible-reconnect, hidden-pause, pagehide-cleanup); cargo `detach→sleep(grace kecil)→reattach` tidak re-reap + default 120s. PING/PONG keepalive 0x05→0x06 tak berubah.

## 5. Konteks untuk Sesi Berikutnya

- **Pola task runner**: `agent_pkg.rs` & `distro_mgmt.rs` keduanya single-slot registry + broadcast line + SIGKILL cancel + WS stream — salin pola ini untuk task async apa pun; jangan buat slot kedua paralel.
- **Invariant argv-only** masih mutlak: semua spawn `Vec<String>` pre-fork; nama paket/agent/env HANYA dari allowlist/map statis; path config HANYA dari map server-side.
- Router9: host terkunci `127.0.0.1`; hanya port numerik dari env — jangan pernah terima URL/host dari klien.
- Backoff constants & guard refs ada di scope attach `.then` `TerminalView.tsx`; cleanup wajib di effect return (pola sama dengan coalescing rAF v0.6.1).
- `layoutHydratedRef` guard (spec 011) mencegah state kosong menimpa layout tersimpan — jangan hapus.
- Wire additive: registry 5 agent mengubah jumlah test eksplisit; `SessionMetadata.env` & labelOverride lama tetap kompatibel.
