## 4. Konteks untuk Sesi Berikutnya

- **argv builder rantai**: `http` → `create_session_with_env(env,agent)` → `PtySession::new_with_env` → `agents::build_agent_argv` (agent menang atas env-only) / `environments::build_argv`. Jangan bungkus shell-string; selalu `Vec<String>` pre-fork.
- **Janitor invariant**: `grace_period==0` ⇒ tidak pernah rekap idle (deadline `None` di semua jalur: create/detach/exit). `busy_grace==0` ⇒ busy-branch off.
- **Coalescing**: `pending` + `raf` dideklarasikan di scope attach `.then`, cleanup di return effect — jangan dipindah ke scope effect luar tanpa guard `ws`.
- **mux-code**: `tokenizeLine` per-line stateless — block comment multi-line belum di-track antar baris (kandidat v0.6.2); highlight layer di-skip bila file >200KB.
- **Bracket auto-close, wrap toggle UI, DOM virtualization penuh, FolderPicker di Agents menu** — ditunda (checklist + handoff ini), kandidat v0.6.2.
- `advertise_addrs`/`allowed_hosts` (009) tidak tersentuh; `SessionMetadata` additive (`env`) — wire lama aman.
